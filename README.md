# Оценка производительности численных методов в задаче ориентации монокулярной камеры

## Запуск

Обработка всего датасета и сохранение результатов в `output`:

```sh
go run ./src
```

Для обработки n изображений используется флаг `limit`

Запуск дешборда с результатами:

```sh
go run ./src/report
```

Сайт всегда читает результаты из папки `output`.

В разделе [«Оценка»](http://127.0.0.1:2107/#quality) показаны
полнота результатов, угловые ошибки RANSAC и SVD относительно эталона `vp`,
максимальная ошибка по изображениям и показатели успеха при выбранном допуске.
Ошибки и допуск измеряются в градусах, доли — в процентах.

## Датасет

[York Urban DB](https://www.elderlab.yorku.ca/resources/york-urban-line-segment-database-information/)
содержит 102 фотографии городских сцен.

MAT-парсер рассчитан на исходные несжатые файлы MATLAB v5 из York Urban DB
с числовыми массивами типа `double`.

В `report.json` сохраняются калибровка камеры, точки схода RANSAC и SVD
и итоговый ортогональный базис. Промежуточные отрезки и диагностические
счётчики в JSON не дублируются.
