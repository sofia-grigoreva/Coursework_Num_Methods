# Оценка производительности численных методов в задаче ориентации монокулярной камеры

## Запуск

Обработка всего датасета и сохранение результатов в `output`:

```sh
go run ./src
```

Для обработки n изображений используется флаг `limit`

Запуск дешборда с результатами:

```sh
go run ./src/report
```

## Датасет

[York Urban DB](https://www.elderlab.yorku.ca/resources/york-urban-line-segment-database-information/)
содержит 102 фотографии городских сцен.
